 ##  🛠️ Instalação :
 
 <p>Primeiro passo, baixe o projeto na sua máquina usando o terminal.</p>
 
```
git clone https://github.com/Stanley-Felix-Bergamo/Site-Set.git
```

<p>Segundo passo, baixe todas as dependências</p>

```
npm install
```

<p>Terceiro passo, use o comando npm run dev, para iniciar o ambiente de desenvolvimento local do projeto</p>

```
npm run dev
```

<p>E pronto, é só acessar no seu navegador</p>

```
http://localhost:3000/
```
